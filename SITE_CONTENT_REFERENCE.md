## 19. DATABASE SCHEMA (Current MySQL → Migrate to Neon/PostgreSQL)

### Table: `projects`

```sql
CREATE TABLE projects (
  id          SERIAL PRIMARY KEY,
  name        VARCHAR(255)   NOT NULL,
  description TEXT           NOT NULL,
  highlights  TEXT           NOT NULL,   -- bullet points separated by \n
  project_details TEXT       NOT NULL,   -- long description
  completion  VARCHAR(100)   NOT NULL,   -- e.g. "Completed Jan 2024" / "Expected Dec 2026"
  category    VARCHAR(50)    NOT NULL,   -- Residential | Commercial | Industrial | Hotel | Gallery
  status      VARCHAR(20)    NOT NULL,   -- completed | ongoing
  created_at  TIMESTAMPTZ    DEFAULT NOW()
);
```

### Table: `project_images`

```sql
CREATE TABLE project_images (
  id            SERIAL PRIMARY KEY,
  project_id    INT            REFERENCES projects(id) ON DELETE CASCADE,  -- NULL = gallery-only
  image_path    VARCHAR(255)   NOT NULL,
  display_order INT            DEFAULT 0
);
```
> `project_id` is **nullable** — NULL means the image is a standalone gallery image.

### Table: `blogs`

```sql
CREATE TABLE blogs (
  id             SERIAL PRIMARY KEY,
  title          VARCHAR(255)   NOT NULL,
  slug           VARCHAR(255)   UNIQUE NOT NULL,
  excerpt        TEXT,
  content        TEXT,           -- Markdown content
  featured_image VARCHAR(500),
  category       VARCHAR(100)   DEFAULT 'General',
  author         VARCHAR(100)   DEFAULT 'Arbee Structures',
  status         VARCHAR(20)    DEFAULT 'draft',   -- draft | published
  views          INT            DEFAULT 0,
  created_at     TIMESTAMPTZ    DEFAULT NOW(),
  updated_at     TIMESTAMPTZ    DEFAULT NOW()
);
```

### Table: `contact_submissions`

```sql
CREATE TABLE contact_submissions (
  id         SERIAL PRIMARY KEY,
  name       VARCHAR(255)   NOT NULL,
  email      VARCHAR(255)   NOT NULL,
  mobile     VARCHAR(50)    NOT NULL,
  message    TEXT,
  status     VARCHAR(20)    DEFAULT 'new',   -- new | read | replied
  created_at TIMESTAMPTZ    DEFAULT NOW()
);
```

## 24. NEON DB MIGRATION NOTES

### Connection
```
DATABASE_URL=postgresql://<user>:<password>@<host>.neon.tech/<dbname>?sslmode=require
```

### Key Schema Changes from MySQL → PostgreSQL

| MySQL | PostgreSQL (Neon) |
|-------|-------------------|
| `INT AUTO_INCREMENT PRIMARY KEY` | `SERIAL PRIMARY KEY` or `BIGSERIAL` |
| `ENUM('a','b')` | `VARCHAR(20)` with CHECK constraint or custom type |
| `LONGTEXT` | `TEXT` |
| `TIMESTAMP DEFAULT CURRENT_TIMESTAMP` | `TIMESTAMPTZ DEFAULT NOW()` |
| `ON UPDATE CURRENT_TIMESTAMP` | Use trigger or handle in app layer |

### Recommended ORM
- **Drizzle ORM** (lightweight, type-safe, works well with Neon)
- Or **Prisma** with `provider = "postgresql"`

### Image Storage for Production
- Move images from `/src/assets/images/` to **Cloudinary** or **Vercel Blob** or **AWS S3**
- Store only the image URL/path in DB (not the full filesystem path)
- Current paths like `/src/assets/images/img1.jpg` → update to `/images/img1.jpg` or CDN URL
